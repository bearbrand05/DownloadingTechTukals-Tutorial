How to Download Tech Tuklas Adventure

Follow the 10 steps below. Each screenshot has a yellow circle showing exactly where to tap. Tap any screenshot to enlarge it.

  • techtuklas.apk · 40.87 MB
  • Android only · won't work on iPhone
  • About 2–3 minutes

What you need

An Android phone, an internet connection (Wi-Fi or mobile data), and at least 100 MB of free storage.

Where's the link?

Open the Google Drive link that was sent to you on Messenger. Step 1 starts there.

About the warnings

You'll see a few "harmful" and "scan" warnings. That's normal for any APK that isn't from the Play Store. Each one is explained below.

PHASE 1

Get the file from Google Drive

Steps 1–3 · You're still inside Messenger's built-in browser here.

01Google Drive

Tap the APK file

When you open the link, you'll see a Google Drive folder named apk. Tap the file techtuklas (1).apk.

What you're seeing: Two files with a gray "APK" icon. An APK is the installer for an Android app, like a setup file on a computer.
02Google Drive

Tap Download

You'll see "No preview available" (shown as "Walang available na preview" if your phone is in Filipino). That's fine. Tap the blue Download button.

Why no preview? Google Drive can't display what's inside an app file. It has to be downloaded.
03Google Drive

Tap Download anyway

A white page with small text will appear. Find the small Download anyway button below the file name and tap it.

What the warning means: "This file is too large for Google to scan for viruses" means the file (39 MB) is bigger than Google scans. "This file is executable" means it's an app that can be installed. Every APK on Drive shows this.
Tip: The button is really small. Pinch with two fingers to zoom in before tapping it.
PHASE 2

Download with Chrome

Steps 4–6 · You'll switch from Messenger to Chrome to finish the download.

04Messenger

Tap CONTINUE

Messenger will ask: "You're leaving our app." Tap the red CONTINUE.

Why this appears: Messenger's browser can't download app files, so it hands the download over to Chrome (or your default browser).
05Chrome

Tap Download anyway again

You're in Chrome now. A "File might be harmful" popup will ask if you still want to download techtuklas (1).apk (40.87 MB). Tap Download anyway.

Why "harmful"? Chrome shows this for every APK that isn't from the Play Store. Just check that the file comes from drive.usercontent.google.com, like in the screenshot.
06Chrome

Tap Open

Wait for the download to finish. When "File downloaded (40.87 MB)" appears at the top, tap Open on the right right away.

Missed the Open button? It disappears quickly. Open your Files or My Files app, go to Downloads, and tap techtuklas (1).apk.
PHASE 3

Install the game

Steps 7–10 · The final stretch.

07Installer

Tap Install

You'll see the Tech Tuklas Adventure icon and name with the question "Do you want to install this app?" Tap Install.

If you see "For your security, your phone is not allowed to install unknown apps": tap Settings, turn on Allow from this source, then go back and tap Install again.
08Play Protect

Tap More details

Google Play Protect will say "App scan recommended." Don't tap either of the pink buttons yet. Tap More details ⌄ in the middle.

Why: The game is new, so Play Protect hasn't seen it before. The option to continue installing is hidden under "More details."
Avoid: Don't install app cancels the install. If you tap it by accident, start again from Step 6.
09Play Protect

Tap Install without scanning

New text will appear underneath. Tap Install without scanning. The install will start.

Alternative: If you'd rather have Google check it first, tap Scan app. It takes a bit longer, and the result shows on the same screen before installing.
10Installed

Tap Open and play

When you see "App installed.", you're done! Tap Open to start the game.

Next time: You'll find the Tech Tuklas Adventure icon on your home screen or app drawer. Open it from there.
Quest complete

Tech Tuklas Adventure is installed!

You can now delete techtuklas (1).apk from your Downloads to free up space. The game will stay installed.
